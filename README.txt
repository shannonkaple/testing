MS. KAPLE'S DOUBLE-CLICK STEM ARCADE

Six games:
1. Catch the Computer! — endless high-score game with slow movement.
2. Reveal the Picture! — full wide picture, no cropping.
3. Open the Files! — double-click the correct folder, then close the fake window.
4. Hidden Picture Hunt! — cartoon classroom image with invisible hotspots.
5. Build It! — match clipart parts to three different STEM stations.
6. Collect Them All! — collect every matching STEM item.

UPLOAD TO GITHUB:
Upload EVERY file in this folder directly to the root of the existing doubleclick repository.
Do not create an assets folder unless you also change the paths in index.html.

Fonts:
KA Homebody Club
VAG Rounded Bold

Cartoon classroom/school-supply clipart used from the user's connected Google Drive.
